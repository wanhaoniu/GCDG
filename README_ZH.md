# GCDG：基于抓取条件依赖图的最小干预目标取出

本仓库对应 CoRL camera-ready 的代码、密集场景 benchmark、模型权重、实验结果与项目主页。与 T-RO 的动态超图项目分开维护。

- Benchmark：500 个场景、12,985 个目标样本、313,228 个抓取候选、6,766,097 条监督边。
- 固定划分：350/75/75 个训练/验证/测试场景，分别为 9,090/1,950/1,945 个目标。
- 同时保留平行夹爪和吸取候选，以及四类依赖标签和最小阻挡集合。
- 发布 29 个已训练模型，并保留全部五个有序检索模型种子的结果。
- 正文和附录的 20 张表提供 CSV/TeX，13 张已确认图片保留在 `paper/figures/`。

安装、下载、训练、测试命令见 [英文 README](README.md)，数据结构和评测范围见 [benchmark 说明](benchmark/README.md)。图数据与论文当前版本一致。

有序检索共四个开发场景，每场景四种目标顺序，每个条件统一为 160 次目标试验。论文展示的 seed 11 在原顺序实验中事后选定，在新增顺序之前固定；所有种子的结果均公开。新增顺序不视为新增独立场景。
